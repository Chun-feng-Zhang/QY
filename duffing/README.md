# 方向 B · Duffing 混沌振子微弱信号检测

> 🚧 骨架占位目录 —— 方向说明、代码与数据待补充。

## 方向简介

利用 **Duffing（杜芬）混沌振子**对初值敏感、相变突变的特性，在强噪声背景下检测淹没的微弱周期信号，属于混沌理论在信号检测中的应用。典型思路：将待检信号作为周期策动力注入临界混沌态的 Duffing 系统，依据系统是否发生"混沌 → 大尺度周期"相变来判定目标信号存在，可检测远低于噪声底的信号。
