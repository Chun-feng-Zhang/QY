# QY 课题代码仓库

射电天体物理观测与信号处理相关研究方向的统一代码库（monorepo）。每个子方向一个目录，各自维护独立的代码、数据与说明文档。

## 子方向索引

| 目录 | 方向 | 状态 | 说明 |
|---|---|---|---|
| [`pulsar_relay/`](pulsar_relay/README.md) | A · 双站共视接力观测 | ✅ 可用 | 洛南 × 杭州双 40 m 射电望远镜脉冲星共视接力 24 h 不间断观测规划 |
| [`duffing/`](duffing/README.md) | B · Duffing 振子单脉冲信号增强 | ✅ 可用 | B1937+21 相干消色散 + 强耦合 Duffing 双振子单脉冲 SNR 增强 |
| — | C · 待定 | ⏳ 规划中 | 后续新增方向在此登记 |

## 约定

- 各方向代码/数据放在自己的子目录内，互不干扰；
- 根级 `.gitignore` 提供通用规则，方向特有的输出文件（图表、CSV 等）可放各自目录并自行补充忽略规则；
- 新增方向：新建 `xxx/` 目录 + `xxx/README.md`，并在上表登记。
